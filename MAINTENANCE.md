# JDH Studio website checkup routine

The site is static and can be reviewed safely before each published update.

## Before publishing

- Check Home, Studio, Services, Work and Contact at mobile, tablet and desktop widths.
- Test the mobile menu and every primary navigation link.
- Submit a test contact form and confirm the Formspree delivery.
- Test each WhatsApp link and confirm its pre-filled message is appropriate.
- Check email and Instagram links.
- Confirm images load, have useful alt text and remain lightweight.
- Check the browser favicon and page titles.
- Review copy for accurate claims and remove placeholder project language when real case studies are ready.

## Collaboration protocol

For each future change, the website reviewer should report findings first, identify any content or brand decision that needs John’s confirmation, and only then implement approved changes. This keeps the site evolving without silently changing positioning or claims.
