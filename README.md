A self-initiated JDH Studio concept: a lightweight interactive service-matching assistant for small-business enquiries.

## Run locally

Open `index.html` directly in a browser. No build step, dependencies, API keys, database, or paid services are required.

## What it demonstrates


This is a concept product, not a live production lead-management system.

# JDH Studio prototype

A self-contained multi-page studio site for JDH Studio. It is intentionally static: no build step, dependencies, API keys, database, or paid services are required.

## Pages

- `index.html` — studio home with the interactive LeadFlow service matcher
- `work.html` — selected work grid
- `about.html` — studio point of view and capabilities
- `contact.html` — project enquiry form that opens a pre-filled email draft

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server. `favicon.svg` is linked by every page.
